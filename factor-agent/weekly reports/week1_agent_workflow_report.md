# 从金融直觉到可执行因子：Agentic Factor Research 系统设计与初步实验

> 历史阶段报告：内容口径截至 2026-11-06。后续 EvoAlpha 工作流、三代实验和最终测试结果见 [Week 2 报告](week2_evoalpha_workflow_report.md)。

> **研究对象：** 美股历史时点 S&P 500 成分股  
> **当前数据：** 日频 OHLCV、市值与成分股区间，2000–2026 年  
> **当前验证区间：** 2015–2019 年；2020–2026 年继续作为锁定测试集  
> **系统目标：** 让多个研究 Agent 自动完成“研究直觉—可检验假设—因子实现—回测评估—研究决策”的闭环

## 一、核心结论

1. **端到端 Agentic 因子研究闭环已经建立。** 系统能够从研究目标出发，调用多个 Research Agents 形成金融直觉和结构化假设，再由 Implementation Agent 转换为可执行 FactorSpec，经过统一回测与 Evaluation Agent 诊断，最后由外层 Manager Agent 决定下一步研究动作。
2. **Agent 在流程中承担了明确的语义研究职责。** Agent 负责文献与因子知识检索、经济机制构造、假设形式化、公式设计、结果解释和研究调度；数据处理、语法校验、回测口径、动作权限和状态持久化由确定性程序控制。
3. **四个研究方向已经能够在同一轮中独立生成并回测因子。** 当前方向包括动量、反转、流动性—波动率和量价关系。系统会在四组完整实验结果产生后，再由 Manager 选择本轮相对最优候选。
4. **当前实验验证了系统能力，但尚未发现达到验收标准的有效因子。** 最近一次四路实验中，四个因子的 Rank IC 均未超过预设的 `0.02` 门槛，说明现阶段主要成果是研究基础设施和自动化流程，而不是已经获得稳定 Alpha。
5. **结果暴露出下一阶段的关键问题。** 自由生成的经济叙事可以较丰富，但从条件性金融机制到可执行公式的转换仍可能损失原假设结构；正的组合收益也可能与接近零或负的 Rank IC 同时出现，因此需要加强增量信息检验、条件结构表达和稳健性评价，而不是仅继续增加 Prompt 限制。

## 二、研究问题与总体思路

传统自动化因子挖掘往往直接搜索公式或组合已有算子，容易产生大量缺少经济解释、信息高度重复或存在过拟合风险的候选。本项目参考 RD-Agent 的闭环研究思想，但不直接修改其源码，而是独立实现一套适用于本地美股数据的 Agentic Factor Research Harness。

系统将研究过程拆分为三个层次：

```text
金融直觉：为什么某种市场状态可能产生未来收益差异？
    ↓
可检验假设：使用现有数据能够观察到什么横截面关系？
    ↓
可执行因子：如何将假设转化为合法、无泄漏的结构化公式？
```

这种拆分使系统可以分别诊断：研究机制是否合理、假设是否可证伪、公式是否忠实实现假设，以及回测结果是否支持原始主张。

## 三、系统架构

### 3.1 外层 Manager 与 LangGraph 工作流

外层 Manager Agent 负责研究层决策，LangGraph 负责流程执行、状态转换和失败路由。每轮工作流为：

```text
Research Goal
    ↓
四个 Specialist Research Pipelines
    ↓
确定性 Hypothesis Checker
    ↓
四路 Implementation → Backtest → Evaluation
    ↓
Manager 比较完整实验结果
    ↓
Accept / Adjust / Revise / New Hypothesis / Reject / Stop
    ↓
Checkpoint + SQLite Research Memory
```

Manager 只能从代码规定的动作集合中选择，达到最大迭代次数后系统自动停止。每个节点的输入、输出、错误和决策均进入 Workflow State 与事件记录，使实验可以恢复、审计和复现。

### 3.2 四个 Specialist Research Pipelines

系统固定保留四种差异化研究视角：

| 研究方向 | 主要关注 |
|---|---|
| Momentum | 信息扩散、趋势延续与拥挤过滤 |
| Reversal | 过度反应、价格冲击与卖压衰竭 |
| Liquidity–Volatility | 流动性变化、风险补偿与波动状态 |
| Price–Volume | 价格与成交量的确认、背离和非线性交互 |

每个 Specialist 内部进一步拆为两个 Agent：

1. **Financial Intuition Agent**：读取研究目标、历史实验、在线资料和因子知识库，构造核心机制、因果链、市场条件、预期模式、2–4 个因子组件及证伪风险。
2. **Hypothesis Formulation Agent**：将金融直觉转化为五日横截面预测假设，明确主信号、条件、确认项和风险控制项，但不直接生成公式。

确定性校验确保第二阶段只能使用第一阶段已经提出的研究概念。若 Agent 输出概念越界、引用不存在或结构不合法，系统会把具体错误反馈给 Agent 并自动重新生成。

### 3.3 Research Evidence 与因子知识库

Research Agent 的研究上下文由三部分组成：

- **实时资料检索**：优先使用 Crossref 学术元数据，失败时回退到无需 API Key 的网页检索；
- **本地因子知识库**：包含 101 个 Alpha101、158 个 Qlib Alpha158 和 20 个经典学术因子，共 279 条；
- **实验记忆**：从 SQLite 中按研究概念、失败原因、历史表现和当前研究方向检索相关记录。

知识库同时标记因子是当前可实现、需要扩展 DSL，还是需要额外数据。Agent 可以借鉴暂时不可实现因子的经济机制，但最终假设必须符合当前 OHLCV 与市值数据能力。

### 3.4 Implementation Agent 与 FactorSpec DSL

Implementation Agent 不直接生成和执行任意 Python 代码，而是输出结构化 FactorSpec。FactorSpec 包括：

- 因子名称、经济描述和来源假设；
- JSON AST 公式；
- 所需字段和最大回看窗口；
- 因子方向；
- 可选价格、流动性和市值股票池过滤条件。

系统使用 Pydantic 验证字段、算子、参数数量、窗口和数据依赖，再由 Polars 编译器生成因子表达式。当前 DSL 支持 OHLCV、市值、滞后、收益率、滚动均值与标准差、横截面排名与标准化、四则运算、比较和条件表达式。结构错误会触发最多四次带验证反馈的自动纠错。

### 3.5 统一数据与回测引擎

全部候选使用相同的确定性回测口径：

- 使用历史时点 S&P 500 成分股，避免当前成分股带来的幸存者偏差；
- 使用 Polars 懒加载处理约 526 万行、1,195 只股票的数据面板；
- 每日对原始因子执行 1%/99% 缩尾、横截面标准化和市值中性化；
- 每周最后一个交易日收盘生成信号，下一交易日开盘交易；
- 选择 Top 20、等权配置，跌出 Top 30 后退出；
- 单边换手成本为 10 bps；
- 每个候选因子的周期明细和汇总结果按 `run_id / iteration / factor_id / attempt` 独立保存。

当前评价的硬性标准为：Rank IC 大于 `0.02`，且交易成本后累计净收益为正。Evaluation Agent 不能改变硬性判断，只负责解释结果并提出后续研究建议。

## 四、开发与验证进展

项目按“先固定流程，再逐步替换内部 Agent”的方式开发：

1. 建立 Workflow State、Manager 主循环、事件日志、Checkpoint 与 SQLite Research Record；
2. 建立真实数据接口、因子清洗、市值中性化和周频 Top 20 回测；
3. 建立 FactorSpec、结构化 DSL、Pydantic 校验与 Polars 编译器；
4. 接入外层 Manager Agent、Implementation Agent 和 Evaluation Agent；
5. 将单一 Research Agent 扩展为四种研究策略；
6. 加入在线资料检索、279 条因子知识库和相关实验记忆；
7. 将 Research 阶段拆为“金融直觉—假设形式化”；
8. 将流程改为每轮四个方向全部实现和回测，再进行候选选择。

当前代码通过 **69 项自动化测试**，覆盖状态结构、工作流路由、候选筛选、Agent 结构化输出、错误重试、FactorSpec 编译、数据处理、回测和 SQLite 记录。

## 五、四路 Agent 初步实验

最近一次完整实验在 2015–2019 验证区间运行。四个 Specialist 均独立完成金融直觉、假设、FactorSpec、回测和评价。

| 方向 | 自动生成的研究假设 | Rank IC | ICIR | 成本后累计净收益 | 年化收益 | Sharpe | 最大回撤 | 平均换手率 | 结果 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---|
| Momentum | 平滑中期动量与成交量降温后的五日延续 | -0.0174 | -0.1064 | 17.59% | 3.28% | 0.28 | -20.17% | 0.600 | FAIL |
| Reversal | 下跌后窄幅承接与卖压衰竭 | 0.0007 | 0.0065 | 32.67% | 5.79% | 0.51 | -19.24% | 0.906 | FAIL |
| Liquidity–Volatility | 流动性持续恢复与日内区间收窄后的五日正向收益 | -0.0060 | -0.0538 | 44.23% | 7.57% | 0.61 | -18.74% | 0.816 | FAIL |
| Price–Volume | 正收益与成交量异常退潮的五日延续 | 0.0004 | 0.0042 | -1.50% | -0.31% | 0.05 | -22.16% | 0.953 | FAIL |

四个因子均未达到 Rank IC 门槛。Manager 最终选择反转方向作为本轮相对最优候选，因为它在保持正净收益的候选中取得最高的正 Rank IC，但 Evaluation Agent 仍将其判定为 `FAIL_HYPOTHESIS`，并建议修订假设而不是接受因子。

## 六、实验诊断

### 6.1 系统层面的有效结果

- 四个 Research Pipelines 能够产生具有不同经济机制的候选，而不是仅修改同一个公式参数；
- 文献、因子知识、历史失败记录和当前数据能力能够进入同一研究上下文；
- Agent 输出能够被确定性接口验证、编译和真实执行；
- 单个方向失败不会阻止其他方向继续完成回测；
- Manager 的选择发生在四组完整实验之后，而不是在缺少实证结果时提前选择；
- 每次失败都保留假设、公式、指标、诊断与下一步建议，为后续研究提供机器可读记忆。

### 6.2 因子表现较弱的主要原因

1. **金融叙事不等于增量信息。** Agent 可以生成逻辑完整的机制，但当前 OHLCV 概念之间可能高度相关，复杂叙事最终仍可能只是已有短期收益、波动率或成交量信号的变体。
2. **条件性假设在公式化时被弱化。** 例如“在近期收益相近的股票中比较盘中承接”属于条件比较，当前 Implementation Agent 可能将其近似为多个排名的线性加总，从而改变原假设。
3. **组合收益与横截面预测能力并不一致。** 部分候选净收益为正，但 Rank IC 接近零或为负，收益可能来自样本期风险暴露、组合构造或少数时期，而不是稳定的股票排序能力。
4. **高换手显著侵蚀收益。** 三个候选的平均换手率超过 0.8，量价因子甚至由正毛收益转为负净收益。
5. **当前数据维度有限。** 系统主要使用个股自身 OHLCV 与市值，缺少可靠的历史行业分类、基本面、分析师预期、期权和新闻等可能提供独立信息的变量。
6. **当前证据仍是单次验证实验。** 尚未完成多时间窗口、随机种子、子样本、参数敏感性和锁定测试集验证，不能从一次运行判断策略稳健性。

## 七、当前贡献与研究定位

本阶段的贡献不是证明 LLM 已经能够直接发现稳定 Alpha，而是建立了一套可验证的 Agentic Research 实验平台：

- 将开放式金融研究与确定性量化验证分离；
- 将“直觉、假设、实现、回测、评价和决策”保存为可追踪的研究对象；
- 支持多个研究方向并行竞争，而不是单路径连续自我强化；
- 允许后续逐步替换 Agent、知识源、DSL 和评价策略，同时保持统一数据与回测口径；
- 能够明确区分“系统运行成功”和“研究假设通过验证”。

## 八、局限与后续工作

### 当前局限

- 四个 Specialist 的研究范围仍由固定方向划分，方向内部的探索多样性有限；
- 因子知识库主要用于参考，尚未系统计算新候选与已有因子的碰撞、相关性和边际信息；
- DSL 尚不能自然表达分组内比较、条件中性化、行业关系和部分复杂时序算子；
- 当前只支持单因子、纯多头、周频、Top 20 等权策略；
- 缺少 SPY 超额收益、退市收益、行业中性化和完整交易可实现性处理；
- 2020–2026 锁定测试集尚未开启。

### 下一阶段

1. 在 Research Agent 生成假设前加入“信息覆盖与碰撞分析”，优先寻找现有因子库未覆盖的信息维度；
2. 对候选执行与 Alpha158、Alpha101 和历史候选的相关性、偏 IC 与增量预测检验；
3. 扩展 FactorSpec，使条件性假设能够表达分组、残差化和交互结构；
4. 将单次因子评价扩展为分时期、分市值、分波动状态和交易成本敏感性检验；
5. 让 Manager 根据失败类型分配后续研究预算，而不是仅选择当前指标最高的候选；
6. 在方法冻结后开启 2020–2026 锁定测试集，进行最终样本外验证。

## 九、阶段性结论

项目已经从“固定函数模拟 Agent”发展为一个能够调用多个真实 Agent、生成四类研究假设、编译结构化因子并完成统一回测的闭环系统。最近一轮实验没有发现通过 Rank IC 门槛的因子，但这并不等同于系统失败：系统准确地拒绝了缺乏稳定横截面预测能力的候选，并保留了可用于下一轮研究的完整证据。

下一阶段的重点将从“把 Agent 接入流程”转向“提高研究信息的独立性和实验反馈质量”，即让 Agent 更系统地寻找因子库尚未覆盖的信号，并确保金融机制在公式实现和实证检验中得到忠实验证。
