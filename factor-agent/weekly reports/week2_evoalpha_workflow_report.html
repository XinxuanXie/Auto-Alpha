阶段性结论

基础闭环已完成

Manager、Research、Implementation、回测、Evaluation 和 Memory 能够形成完整、可恢复的研究流程。

搜索机制已升级

EvoAlpha 从既有因子出发，用 Refinement、Crossover 和 Mutation 进行三代结构化搜索。

预测改善不等于收益改善

最佳新因子跨区间提高 20 日 IC 并降低换手，但样本外收益、Sharpe 和回撤未优于原因子。

基础 Agent 工作流：完成了什么

研究层

动量、反转、流动性—波动率和量价关系四个 Specialist，分别完成金融直觉与可证伪假设。

执行层

Implementation Agent 输出 FactorSpec；程序校验并编译为 Polars 表达式，统一清洗和回测。

编排层

Manager 与 LangGraph 控制流程、重试和决策；SQLite 与 Checkpoint 保存实验和恢复状态。

首轮结果

四个真实候选均未达到 Rank IC 门槛，说明平台闭环成立，但开放式新因子生成的有效率较低。

下一阶段

改进选择目标

  • 将父子指标增量纳入准入规则
  • 采用 IC、稳定性、收益、换手、回撤和复杂度的多目标选择
  • 避免只优化 IC、忽略投资表现

提高有效子代比例

  • 分别统计 Refinement、Crossover 和 Mutation 的增量贡献
  • 在训练期内部加入滚动验证
  • 保持最终测试集冻结，降低反复试验造成的过拟合

总结

本周的核心成果是把研究方式从“Agent 每轮自由生成新想法”升级为“从已有因子出发、基于回测证据进行可追踪进化”。最佳因子的 20 日预测能力在训练、验证和测试中均优于原因子，但组合收益没有同步改善。下一步将把父代相对改进和多目标选择写入进化协议，以提高真正有效因子的产出率。
