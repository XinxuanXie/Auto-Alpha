# 从基础 Agent 工作流到 EvoAlpha 因子进化

> 阶段进展报告 · 2026-11-08
> 研究对象：历史时点 S&P 500 成分股上的日频横截面单因子研究

## 一、阶段结论

本项目已完成两套彼此独立、共享确定性研究基础设施的工作流：

1. **基础 Agent 工作流**：验证 Manager、Research Agent、Implementation Agent、统一回测、Evaluation 与 Memory 能否形成完整闭环；
2. **EvoAlpha 工作流**：不再要求 Agent 从零提出因子，而是从已有 Alpha158 因子出发，通过单父代改进、双父代交叉与变异进行多代搜索。

三代真实 EvoAlpha 实验完成了 **84 次子代回测**。最佳新因子在训练、验证和最终测试三个区间均提高了 20 日 Rank IC，并持续降低换手率；但其样本外收益、Sharpe 和最大回撤没有优于原因子。因此，当前结果支持“中期横截面预测增量具有一定稳定性”，尚不支持“新因子形成了更优的多头投资策略”。

## 二、上周：基础 Agent 研究闭环

基础版本的目标是先建立一套可运行、可追踪、可替换内部模块的自动研究系统。

```text
Research Evidence / Memory
        ↓
Financial Intuition Agent
        ↓
Hypothesis Formulation Agent
        ↓
Implementation Agent → FactorSpec
        ↓
统一清洗、单因子回测与 Evaluation
        ↓
Manager 决策 → SQLite Record / Checkpoint
```

系统包含动量、反转、流动性—波动率和量价关系四个研究方向。Agent 负责研究判断与结构化表达；确定性代码负责数据边界、公式语法、回测口径、流程路由和持久化。

第一轮四个真实候选均未达到 `Rank IC > 0.02` 的硬性门槛。该结果说明基础闭环能够工作，但开放式 Prompt 即使能产生合理金融叙事，也难以稳定产生具有增量预测能力的新因子。

## 三、本周：为什么转向 EvoAlpha

基础工作流暴露出三个问题：

- 每轮从零提出假设，成功结构无法稳定继承；
- 金融叙事可能只是已有价量信号的重新表述；
- 回测反馈主要用于接受或拒绝，尚未直接改变下一轮公式搜索。

因此，本周新增独立的 EvoAlpha 分支。核心思想是把 LLM 从“自由生成最终因子”改为“具有金融语义的进化算子”：它围绕已有因子做局部改进或组合，确定性系统负责验证、回测、比较和种群更新。

旧 Agent 工作流继续保留；EvoAlpha 作为并列实验分支复用 FactorSpec、Polars DSL、历史成分股数据、单因子评价和回测引擎。

## 四、EvoAlpha 工作流

```text
157 个可执行 Alpha158
        ↓ 训练期评价
Top 30 初始种群
        ↓
┌──────────────────────────────────────────┐
│ 每代：12 Refinement + 8 Crossover + 8 Mutation │
│ 结构校验 → 单因子回测 → 相似度准入 → Top 30 更新 │
└──────────────────────────────────────────┘
        ↺ 共 3 代
        ↓
冻结公式与方向 → 验证集排序 → 最终测试一次
```

每代最多评价 28 个新候选：

- **Refinement**：围绕一个父代执行一次主要修改；
- **Crossover**：融合两个低相关父代的互补结构，并保留交叉中间因子；
- **Mutation**：在交叉中间因子上再执行一次受控变异。

Agent 只能输出受限 FormulaSpec AST，不能执行任意 Python。公式字段、窗口、复杂度、数据覆盖、相似度和完全重复均由确定性代码检查。

## 五、实验协议

| 项目 | 设定 |
|---|---|
| 数据 | 历史时点 S&P 500 成分股；日频 OHLCV 与市值 |
| Warm-up | 2000 年 |
| 训练集 | 2001–2010 |
| 验证集 | 2011–2012 |
| 最终测试集 | 2013–2025，一次性冻结测试 |
| 初始因子 | 157 个可执行 Alpha158；排除缺少真实数据的 VWAP0 |
| 主要目标 | 20 日未来收益 Rank IC；5 日和 10 日用于一致性诊断 |
| 组合诊断 | 周频 Top 20 等权，跌出 Top 30 退出，10 bps 成本 |
| 模型 | Refinement/Mutation 使用 DeepSeek Chat；Crossover 使用 DeepSeek Reasoner |

因子方向仅由训练期确定，验证和测试阶段冻结。LightGBM 不参与种子选择、父子比较或种群更新。

## 六、三代真实搜索结果

| 代数 | 回测候选 | 通过硬检验 | 相似度准入 | 进入下一种群的新子代 |
|---|---:|---:|---:|---:|
| 第 1 代 | 28 | 28 | 14 | 11 |
| 第 2 代 | 28 | 28 | 13 | 9 |
| 第 3 代 | 28 | 28 | 10 | 9 |
| **合计** | **84** | **84** | **37** | — |

最终种群包含 5 个原始种子和 25 个进化子代。验证集最佳新因子为 `G02-CROSS-006-INTERMEDIATE`，由 Alpha158 的 `IMXD30` 与 `MIN5` 组合得到。

一次公式审计发现最终 30 个 ID 只对应 26 条唯一公式，说明旧准入逻辑没有先拦截结构完全相同的候选。代码已经加入规范化公式指纹与 `exact_formula_duplicate` 硬拒绝；历史运行结果保持原样，作为可审计记录。

## 七、最佳新因子相对原因子 MIN5

### 预测能力

| 数据集 | 20 日 IC：MIN5 | 20 日 IC：新因子 | 增量 | 20 日 ICIR 增量 |
|---|---:|---:|---:|---:|
| 训练 2001–2010 | 0.02572 | 0.03358 | **+0.00787** | **+0.10185** |
| 验证 2011–2012 | 0.03205 | 0.03298 | **+0.00093** | **+0.12208** |
| 测试 2013–2025 | 0.00754 | 0.01274 | **+0.00520** | **+0.04334** |

20 日 IC 在三个数据集均提高，说明中期预测增量并非只出现在训练期。

### 可交易性与风险

| 数据集 | 年化净收益增量 | Sharpe 增量 | 换手率变化 | 最大回撤变化 |
|---|---:|---:|---:|---:|
| 训练 | +2.19pp | +0.086 | -18.92pp | 改善 2.50pp |
| 验证 | -4.17pp | -0.249 | -19.52pp | 恶化 6.52pp |
| 测试 | -2.32pp | -0.104 | -19.81pp | 恶化 3.01pp |

换手率下降在三个数据集保持一致，但训练期的收益改善没有延续到样本外。预测指标和 Top 20 多头组合表现并不等价：更高的横截面 IC 可能分布在持仓阈值之外，也可能与风险暴露、信号幅度和组合构造发生交互。

## 八、原始因子库长期基准

为避免只围绕短样本解释结果，我们还对 157 个 Alpha158 因子完成了全历史诊断：

- 27 个年度窗口；
- 23 个五年滚动窗口；
- 18 个十年滚动窗口；
- 8 个二十年滚动窗口；
- 合计 11,932 条“因子 × 窗口”结果。

该基准显示因子有效性具有明显时变性。它用于描述因子的历史稳定性与候选来源，不作为无前视交易结果，因为每个窗口内部重新确定了因子方向。

## 九、现阶段贡献与局限

### 已完成的贡献

- 搭建了从开放式 Agent 研究到结构化因子实现、回测、记录的完整闭环；
- 在独立分支实现了可复现的三代 EvoAlpha 搜索；
- 将 LLM 决策与数据、公式、回测和样本隔离等硬约束分离；
- 建立了父代—子代谱系、相似度准入、公式去重和训练/验证/测试冻结协议；
- 获得了跨三个数据集均为正的 20 日 IC 增量证据。

### 当前局限

- 当前 Fitness 主要强调 IC、ICIR 和稳定性，没有强制要求相对父代改善收益与回撤；
- 只有 OHLCV 与市值，缺少真实 VWAP、历史行业分类和基本面信息；
- 三代实验的搜索预算仍较小，且只完成一次模型与 Prompt 配置；
- 大规模搜索存在多重检验和过拟合风险；
- 当前最佳结果属于“预测改进”，尚未转化为更优的可交易组合。

## 十、下一步

下一阶段的目标是提高“有效子代”的比例，而不是继续扩大开放式 Prompt：

1. 将父子指标增量纳入准入规则，优先保留真正超过父代的候选；
2. 使用多目标或 Pareto 选择，同时考虑 IC、稳定性、换手率、收益、回撤与复杂度；
3. 统计每种操作的有效率，比较 Refinement、Crossover 和 Mutation 的真实增量贡献；
4. 在训练期内部使用滚动验证，降低单一区间评分带来的偶然性；
5. 保持最终测试集冻结，后续方法改动使用新的预注册测试区间或扩展数据验证。

## 总结

本周最重要的进展不是发现了一个全面优于基准的交易因子，而是把系统从“Agent 每轮自由提出新想法”推进为“围绕已有因子、依据回测证据进行可追踪进化”的研究框架。当前最佳因子证明 EvoAlpha 可以提高中期横截面预测能力并降低换手，但也暴露出预测目标与投资目标不一致的问题。下一步需要把父代相对改进和多目标选择正式写入进化协议。
