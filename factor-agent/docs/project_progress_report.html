确定性研究基础设施

统一数据与回测

历史时点 S&P 500 成分股；2015–2019 验证期；周频 Top 20 等权；跌出 Top 30 退出；10 bps 成本。

统一因子处理

1%/99% 缩尾、横截面标准化、市值中性化；收盘生成信号，下一交易日开盘成交。

结构化安全接口

Agent 只输出 FactorSpec；Pydantic 校验后由 Polars 编译，不执行任意生成代码。

为什么流程成功，因子仍然较弱？

金融叙事不等于增量信息

多个概念可能仍来自相同的短期价量信息，复杂叙事最终可能只是已有信号的变体。

条件结构在公式化时被弱化

“在相似股票中比较某状态”可能被近似成多个排名的简单相加，偏离原假设。

组合收益不能替代预测能力

正净收益可以与接近零或负 Rank IC 同时出现，可能反映风险暴露或样本期特征。

高换手与有限数据约束

多数候选换手率较高；当前主要使用 OHLCV 与市值，独立信息维度仍然有限。

下一阶段

  1. 加入信息覆盖与因子碰撞分析。 优先寻找现有因子库未覆盖的信息，而不是继续堆叠同源价量信号。
  2. 强化增量评价。 对候选计算与已有因子的相关性、偏 IC、分时期表现和交易成本敏感性。
  3. 扩展 FactorSpec。 支持分组内比较、条件残差化和更忠实的交互结构。
  4. 让 Manager 按失败类型分配研究预算。 区分假设失败、实现偏差、高换手和数据缺失。
  5. 冻结方法后开启 2020–2026 测试集。 完成最终样本外验证。
