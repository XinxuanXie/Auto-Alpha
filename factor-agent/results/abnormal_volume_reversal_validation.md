# 异常放量反转因子：回测引擎验证

运行区间：2015-01-01 至 2019-12-31，仅使用验证段。

## 固定口径

- 历史时点 S&P 500 成分股
- 周末收盘生成信号，下一交易日开盘成交
- Top 20 纯多头、等权
- 横截面 1%/99% 缩尾、标准化、市值中性化
- 10 bps 单边换手成本

## 运行结果

| 指标 | 数值 |
|---|---:|
| 周期数 | 261 |
| 目标持仓次数 | 5,220 |
| 缺失成交价次数 | 8 |
| 平均实际持仓数 | 19.9693 |
| 平均单边换手率 | 0.9383 |
| 累计毛收益 | 86.43% |
| 累计净收益 | 45.99% |
| 年化净收益 | 7.83% |
| 年化波动率 | 18.18% |
| 年化 Sharpe | 0.5062 |
| 最大回撤 | -24.88% |
| 平均 Rank IC | 0.000434 |
| Rank ICIR | 0.00661 |

## 结论

数据加载、历史成分股过滤、因子清洗、市值中性化、下一交易日开盘执行、换手成本和结果落盘已经形成可运行闭环。

该手写因子的 Rank IC 接近零，当前结果不足以证明稳定的横截面预测能力。较高换手率使 10 bps 成本显著降低组合收益。该实验用于验证回测引擎，不进入正式因子库。

当前收益是绝对组合收益，未扣除 SPY 基准。后续评价模块需要加入超额收益、分位数组合、年度稳定性和退市收益处理。
